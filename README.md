# Student Performance Prediction Prototype

This repository contains a lightweight prototype for predicting a student's final grade based on several input features.

## Overview
- **Frontend**: Simple, modern web UI built with HTML, CSS and JavaScript.
- **Backend**: Minimal Flask API that loads a pre‑trained scikit‑learn model (`model.pkl`).
- **Model**: A `RandomForestRegressor` trained on synthetic data (you can replace it with your own dataset).

## Quick Start (Windows)
1. **Install Python 3.11+** if you don't have it.
2. Open a PowerShell window in this folder:
   ```powershell
   cd "C:/Users/dhana/AIML PRO/student_performance_prediction"
   ```
3. **Create a virtual environment & install dependencies**:
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
4. **Train the model** (only needed the first time or when you replace the data):
   ```powershell
   python train_model.py
   ```
5. **Run the Flask server**:
   ```powershell
   python app.py
   ```
   The server will start at `http://127.0.0.1:5000`.
6. Open a browser and navigate to `http://127.0.0.1:5000` — the UI will load.

## Deploy to Render
1. Push this project to a GitHub repository.
2. In Render, choose **New + → Blueprint**, connect the repository, and select this project folder as the Blueprint directory if the repository contains other folders.
3. Render will use `render.yaml` to build and start the web service. When the deploy finishes, open the service URL shown in the Render dashboard.

The free service uses local SQLite storage, which is temporary on Render. Prediction history may be cleared when the service restarts or redeploys.

Replace `train_model.py` with your own data loading and training logic, then re‑run it to produce a new `model.pkl`.
